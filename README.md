  
# 🛒 Supermarket Billing System (Python)

## 📌 Description

The **Supermarket Billing System** is a Python-based application designed to simulate a real-world billing process in supermarkets. This program allows users to input multiple items, their prices, and quantities, and then automatically generates an **itemized receipt**. Discounts can be applied based on conditions such as total amount, item type, or promotional offers.

The project makes use of **loops, conditional statements, and interactive input handling** to ensure a smooth and user-friendly billing process. It is ideal for beginners learning Python fundamentals like **control structures, loops, functions, and user interaction**.

---

## 🚀 Features

* ✅ Add multiple items in a single transaction.
* ✅ Input item **name, price, and quantity**.
* ✅ Apply **discounts** based on conditions (e.g., total bill above threshold).
* ✅ Display **subtotal, discount amount, and final total**.
* ✅ Generate an **itemized receipt** with clear formatting.
* ✅ Interactive: keeps asking for items until billing is completed.

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/supermarket-billing-system.git
   cd supermarket-billing-system
   ```

2. Run the program:

   ```bash
   python billing_system.py
   ```

3. Follow the on-screen prompts to enter items, prices, and quantities.
